# Sentinel Reputation Office – Site one‑page

Site one‑page de **Sentinel Reputation Office**, bureau privé de réputation, confidentialité et gestion de crise pour familles très fortunées (UHNW), family offices et dirigeants exposés.

## Contenu

- `index.html` : structure et contenu du site  
- `style.css` : design sobre, premium, responsive

## Usage

Ce site est destiné à :

- Présenter l’offre tout‑en‑un (audit, veille, réduction de surface d’attaque, coordination de crise, formation).  
- Servir de support de présentation pour les partenaires et prospects (family offices, avocats, banques privées, assureurs).

## Déploiement

Hébergeable gratuitement sur :

- GitHub Pages  
- Netlify  
- Vercel  
- Ou tout hébergement statique classique
